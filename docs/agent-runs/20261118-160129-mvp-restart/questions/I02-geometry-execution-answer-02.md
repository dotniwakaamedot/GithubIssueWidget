- 宛先 `/root/drag_design`。対象 `questions/I02-geometry-execution-question-02.md`。PTY の process group と console signal の影響範囲が確認できないため、Ctrl+C を送らず保留した判断を維持する。
- 親の判断: 対象はこの作業で担当が生成・起動した診断専用プロセスで、ユーザーアプリの設定や未保存データを保持する目的のものではないことを担当が確認する。対象の穏当な停止が判別できない場合、app PID `21312` と server PID `22956` の**個々の PID のみ**、所有・作成時刻・実行パス・command line と対象 version を停止直前に再照合して `Stop-Process` により停止してよい。PID 再利用・一致不能・他者の process の可能性があれば操作せず保留し報告する。
- 停止は app、続いて server を個別に行う。子孫を列挙して一括停止しない。停止後に残る個別の子があれば、所有・使用状況を記録して親の追加判断を待つ。端末以外のデスクトップや既存ユーザーアプリには触れず、推測座標の UI 入力を行わない。
- 既存の専用 scratch・ログ・証拠と元製品は保持する。各操作の対象 PID、直前の識別根拠、時刻、終了結果と**強制終了**であることを記録し、所有 handle の poll・terminal / exit code と PID・port の状態を確認。timeout・取得不能・予期しない残存を成功扱いしない。状態が不明なら後続処理を止め親に連絡する。
- 同じ画像取得、getState / browser inventory、ドラッグを再試行しない。新 geometry 版の準備・起動は、所有 process と port の終了・非競合が確認できた後に、既存確定依頼の保護条件と対象版を再照合して行う。入力は画像・AX・境界と安全条件が揃うまで禁止。
