# I02 B03 依存一覧の読取失敗 01

- 担当: `/root/build_verification`、宛先: `/root`、`/root/restart_planner`。
- 現象: PowerShell 5.1 の `ConvertFrom-Json` が `widget/package-lock.json` のキーを扱えず1回失敗した。後続の要約は null を基に出力されたため無効であり、依存の判定根拠としない。
- 原因候補: PowerShell 5.1 の JSON オブジェクト変換において空キー等を受理できない可能性。実際の該当キーは未確認。
- 対応: 同じ変換を再試行せず、Node.js の `JSON.parse` を用い、明示的な例外処理のある読み取りに切り替える。元の lockfile は変更しない。
- 同種失敗: 今回1回。2回目は該当操作を止めて別担当の客観調査を依頼し、3回目は全作業中止。
- 待つ範囲: 依存審査の結果が得られるまで、依存の導入・実行は行わない。独立した対象版・環境の読み取りは可能。
