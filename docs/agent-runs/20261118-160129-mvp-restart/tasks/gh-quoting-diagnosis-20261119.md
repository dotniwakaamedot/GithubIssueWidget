## 推奨対応

- PowerShell からの GitHub 情報取得は `gh ... --json` の構造化 JSON をまず変数に受け、直後の `$LASTEXITCODE` を確認してから `ConvertFrom-Json` で解釈し、`Where-Object` で必要なフィールドだけを抽出する。出力にはトークンや非公開本文を含めない。入力に基づく値をコマンド文字列へ連結して実行せず、ネイティブ引数として明示する。
- `--jq` や引用符を含むネイティブ引数が本当に必要な場合は、対象 PowerShell バージョンと呼び出し経路を明記し、秘密を含まない小さな引数で実際に子プロセスへ渡る値を別の安全な試験で確認する。過去に失敗したコマンドを漫然と反復しない。失敗・不明時は目的の読取りや外部変更を成功とせず、後続の依存操作を保留する。
- `gh` の終了コード確認と JSON の解析エラーは別々に扱う。ページ数や結果の空配列とエラーを混同せず、必要な全ページと読戻しを確認する。GitHub 側の状態更新が伴う場合は、応答不明時に識別子で照合してから次の操作を判断する。
