## 再発防止

1. 既存ファイルの変更は、同じパスに一つの `Update File` 操作を使い、削除と追加を同じパッチに併記しない。
2. 対象ファイルを適用直前に読み、同一ファイル内の複数 hunk は現行ファイルの上から下へ並べる。アンカーが一意か確認し、独立した変更は小さなパッチに分ける。並べ替えは内容の正しさや競合の不存在を保証しない。
3. 失敗後は対象版と必要な実際の差分を再確認し、失敗を成功扱いしない。書換え・再試行前に該当する失敗回数とユーザー指示を確認する。今回の依頼では別担当による調査を実施したが、今後の同種失敗を数えないことや停止条件の変更を意味しない。
