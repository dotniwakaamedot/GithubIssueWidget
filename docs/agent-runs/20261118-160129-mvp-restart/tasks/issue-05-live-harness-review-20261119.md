**非 blocking の制約:** 別の新規ディレクトリを与えればコードは再度実行でき、同一マーカー照合も内部では行わない。最初の結果が不明または照合できない場合は別ディレクトリでも再送せず、結果と元ディレクトリを保持する。重複検索は競合を完全に排除する原子的なロックではない。実行前の対象・権限・ラベル照合と、実行後の Issue 番号・状態・ラベルの読戻しを計画どおり行う。

依頼、計画、実コード・差分を読み取り専用で確認。作者申告の `cargo test --locked --no-run` 成功は独立再実行・保存ログ照合をしていない。実 GitHub 書込み、トークン操作、テスト実行は行っていない。今回の確認で新たな失敗や教訓はない。
