# 構造化データ生成の失敗 01

- 承認済み方式による依頼作成中、PowerShell で構造化データ生成時に `ArgumentException: 引数の型が一致しません` が1回発生した。対象・停止条件を検査する前、一時ファイル作成前に処理は止まった。依頼書・成果物の公開、製品変更、外部更新はしていない。
- 親は、前回2件の依頼内容検査不一致とは発生段階・現象が異なるため、今回の型エラーを別分類の初回と判断した。依頼内容検査の失敗2件は引き続き履歴として保持する。
- 型エラーは .NET の汎用 List を PowerShell の配列式へ変換する部分で発生した可能性があるが、実行時の細部は未確認。失敗を再現せず、汎用 List と配列式を組み合わせない方式を設計・採用する。発生段階ごとに異なる診断を持ち、不備時の依存操作を止める。
- 同種の問題が初回を含め2回発生したら該当操作を中断し、別担当に客観調査を依頼する。同種3回目で全作業を中止する。過去のドラッグ不成功・文字破損の経路も再試行しない。
