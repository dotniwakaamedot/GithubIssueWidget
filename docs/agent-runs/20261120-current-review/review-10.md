判定: **要修正（blocking 1 件）**。スクリプトを実行せず、ソースと局所的な PowerShell の標準エラー処理を確認した。

## blocking: PowerShell 5.1 で標準エラーが終了例外になる

- 根拠: `readonly-execute-09.ps1:1,17` は `$ErrorActionPreference = 'Stop'` のまま `cargo ... 2>&1` を実行する。現在の PowerShell 5.1 では、標準エラーを出す無害なローカル子プロセスで同じ設定を試し、`catch` に入ることを確認した。Cargo は通常の進捗も標準エラーに出力するため、終了コードや成功要約を確認する前に中断し得る。
- 影響: 試験が正常でも実行スクリプトが想定どおり結果を報告できず、未処理エラーの表示も起こり得る。実際の対象 Cargo コマンドは未実行であり、対象試験での現象は未確認。
- 修正案: 資格情報を含み得る出力を外へ流さずに標準出力・標準エラーを安全に取得できる方法へ変更し、成功時の標準エラー、終了コード非ゼロ、実行不能、機密検出の経路と環境復元を、ダミーの子プロセスだけで確認する。生出力を未保護のファイルに保存しない。
