# 実 GitHub 隔離ハーネスの事前レビュー

判定: **要修正（blocking 3 件）**。書込みを開始しない。対象は指定された隔離ソース版に限る。テスト、認証情報取得、実 GitHub への書込みは行っていない。

## blocking

1. **コンパイル不能の可能性**: `creation.rs:299-301` の `added.unwrap()` はエラー型 `WriteFailure` に `Debug` を要求するが、同ファイル `:50` の型にその実装がない。ビルドが成立せず試験を起動できない。修正後に対象版を更新し、隔離環境のビルド結果を確認する。
2. **異常時に Issue タイトルを出力する**: `creation.rs:229` の `assert_eq!` は不一致時に GitHub から取得した実タイトルをパニック出力に含める。計画のタイトル非出力に反し、誤対象や外部変更時に Issue 情報が露出し得る。値を出さない boolean 判定と固定メッセージに変更し、不一致時の出力を合成値で確認する。
3. **事前照合の不完全なデータを正常と扱う**: `creation.rs:279-282` は各 Issue の `title` や `body` が欠落・型不正でも空文字に置き換えてマーカーなしとする。計画では不完全な取得時は POST を禁止しており、異常応答で既存マーカーを見逃し重複作成する可能性がある。title は文字列を必須にし、body は GitHub の null を明示的に許容しつつ欠落・不正型を拒否するなど、完全性を検査したうえで照合する。欠落・不正型と正規 null の試験を追加する。
