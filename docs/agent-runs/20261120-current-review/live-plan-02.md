# 実 GitHub 検証計画 02

## 承認と対象

- 一次情報: ユーザーは「現在の進行状況を確認しアプリの完成まで進行してください。一度の処理で2度同じ失敗をした時は停止してください」と依頼。公開の現在リポジトリで不足２ラベルと検証用 Issue １件を作成・移動後クローズし履歴とラベルを残す案に対し「書き込みを承諾します。」と回答。既存 Issue や PR の変更は承認対象外。
- 対象 dotniwakaamedot/GithubIssueWidget。新設 status:todo・status:done と既存 status:in-progress・enhancement の存在を実施前に１回の一覧で再確認。検証中に不明・不一致なら書込みしない。
- 固定マーカー giw-live-d295bc126897471ba7ddcc661216143b。タイトルは「GitHub Issue Widget 検証 giw-live-d295bc126897471ba7ddcc661216143b」、本文は検証と終了後クローズを説明し同一マーカーを含む。公開情報として扱い、個人情報や秘密を入れない。
- 事前に Issue 全状態・全ページを GET しタイトルと本文のマーカーをメモリー内で完全照合。正常に全ページ取得でき一致０件の場合のみ１回 POST。検索不完全・複数一致・不明なら中止。実行専用ディレクトリを一意名で新規作成できた場合だけ進み、再実行防止の記録を残す。

- 現行 main.rs SHA256 021488C4C1615EBEFA3185EBDF024A43547657E357715957128F403541A67A97、creation.rs SHA256 61FB68E208B231664DB236E50A37BBB4870763AD61C0071383BACA5730982A87、movement.rs SHA256 ED49F4BA52C6887BCE427E4A6664D335092A1C3311E1B1ED61B4CE322791ABA5。作業場所は隔離コピーとし、製品実装を固定して Rust 試験ハーネスを付加する。コピー差分と試験実行ファイル SHA256、手順とログの扱いは実行前に別担当が確認する。
- アプリの create_in_repo で Todo を作り、受け取った番号だけを対象に固定する。後続の各書込み前に GitHub から対象 Issue を GET し、番号、対象 repo の URL、タイトルと本文のマーカーが一致する場合だけ続行。存在確認できなければ以降の書込みをしない。
- 検証 Issue のみに既存 enhancement ラベルを追加し、正常応答を確認。６方向は Todo→In Progress→Todo→Done→In Progress→Done→Todo とし、最後に Todo→Done でクローズする。各ステップ後に GET して、Todo は open＋status:todo、In Progress は open＋status:in-progress、Done は closed＋status:done、いずれも他の status ラベルなし・enhancement ありを確認する。
- エラー・結果不明・マーカー不一致・不完全な読戻しでは後続の書込みを停止。対象と結果の読戻しだけを行い、作成結果が不明なまま POST を再送しない。停止時は実際の Issue 状態と未完了を記録し、ユーザーの追加指示を待つ。

## 秘密、記録、停止

- gh 認証情報は取得プロセスの標準出力からメモリーだけで受け、コマンド引数・ログ・ファイル・画面に出さない。子プロセス環境に一時設定し、元の各環境変数の値と存在を finally で復元する。試験標準出力・標準エラーはメモリーで取得し、秘密・本文を含み得る生データは保存しない。画面には対象識別子・Issue 番号・固定の段階結果のみ出す。
- ハーネスの子プロセス構成・終了とストリーム待機の上限を実行前に確認し、タイムアウト・中断で子の終了が確認できない場合は実行結果不明として扱う。OS、強制終了や外部ライブラリによる完全な秘匿・終了保証は主張しない。
- 隔離ディレクトリは新規作成し、OS のユーザー権限に従う。秘密や本文は保存せず、作成操作の確認記録・非機密の対象版と結果のみ保持。保持期限は未確定として保護し、削除は別途確認する。書込み結果不明時の読戻しと復旧記録を優先。
- 今回の処理は本再開から停止・終了まで。ユーザー指定の同種失敗は操作対象・原因が同じ実際の失敗を１回ずつ記録し、この処理で累計２回に達したら他の作業を含め停止。書込み操作を出力確認だけで再実行しない。
- 結果記録先 docs/verification-20261120.md と共有 run。Issue URL、対象 SHA、各期待値・結果、未検証と残る問題を区別する。実 UI・PAT 登録・再起動・全 DPI は対象外。
