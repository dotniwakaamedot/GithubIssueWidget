記録日: 2026-11-21。ユーザーの依頼は「issueを確認し、アプリを完成させてください。同じ失敗が2度続いた時は引き継ぎの資料を作成して、セッションを中断してください。」その後「続行してください」と指示があった。

## 停止理由と観測

今回の処理で隔離設定のリリース版 GUI が２回続けて終了コード101で終了したため中断した。F-078 発生3・4として `docs/failure-log-001.md` に記録。２回目の標準エラーは固定分類で panic と WebView2 文字列を含み、Tauri の `failed to run widget` と `Access is denied` は含まず、`os error` 番号は一致なし。標準エラーは上限を超えていない。自由文は保存しておらず、原因や panic 箇所は未特定。WebView2 の存在だけで原因を断定しない。

１回目は `gui-fixture-03`、２回目は `gui-fixture-04` を空の APPDATA・LOCALAPPDATA とした。設定操作・資格情報操作・実 GitHub 書込みは行っていない。Windows Credential Manager 自体は環境変数で隔離されないため、fixture は保持する。２回目は `gui_probe.py` で標準出力・標準エラーを同時に上限付きで読み、固定分類のみを表示した。実行前の合成試験は大量出力の上限、合成秘密の非表示、終了コード、タイムアウトと子プロセス終了を確認し成功。すべての実行環境や秘密検出を保証するものではない。
