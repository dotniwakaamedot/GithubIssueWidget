# GUI 診断分類の独立レビュー

判定: **分類関数の限定範囲で承認**。結果の値は固定キー、真偽値、定数リストから選択された文字列のみで、標準エラーから任意の数値や自由文を返さない。無効な入力は固定メッセージの `ValueError` にする。これは実行手順全体の承認ではない。

## 確認と検証

- 対象 SHA は依頼と一致。`classify` は bytes 以外、32768 バイト超、bool 以外の overflow を拒否し、最大長以下を UTF-8 置換付きで処理する。複数の許可 HRESULT は定数の順に一度ずつ返す。任意の OS エラー番号は出力しない。
- `python -B -m unittest -v test_gui_classifier` を共有場所で実行。終了コード0、3件成功。秘密らしい文字列の非出力、未知 HRESULT、複数値、16進文字に隣接した場合、上限超過と型の一部を検査する。
- 対象外・未確認: プロセス捕捉、呼出側の例外・ログ、fixture や資格情報の隔離、Windows での実アプリ起動と終了。分類関数だけではこれらの安全を保証しない。

## 注意と追加試験候補

HRESULT は文章中の許可値の出現を検出するだけで原因の確定ではない。`crates` も部分文字列の検出であり、ソース位置を確定しない。`overflow=true` の場合は先頭以外の情報を判定できず、不一致を不存在の証拠にしない。既存テストは無効な overflow 型、正確な上限と上限超過の境界、重複一致、全定数、非 UTF-8 の組合せを網羅していない。返却形式の安全性は静的確認したが、必要な呼出側はこれらを追加試験し、実際に表示する値を検査すること。
