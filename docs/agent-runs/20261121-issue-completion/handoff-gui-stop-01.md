# GUI 起動の同種失敗による中断・引き継ぎ

記録日: 2026-11-21。ユーザー原文: 「Issue を確認しアプリを完成させてください。一回の処理の間に同じ失敗が２度続いたらそこまでの経過を引き継ぎ用ファイルに保存して、セッションを中断してください。」

## 停止理由

隔離設定を使用した GUI の起動後、期待した継続動作を確認できない事象が前回と今回の２回続いたため、安全側に数えて中断した。詳細は `docs/failure-log-001.md` の F-078 発生1・2。今回のプロセスは PID 48268、終了コード101。初回は終了コードを取得していない。実行版と起動方法は異なり、内部原因の共通性やアプリ本体の不具合は未確認。再実行・追加調査は停止した。２つの GUI fixture を含む既存ファイル・変更は削除しない。

## 直前の進捗

- 公開リポジトリ `octocat/Spoon-Knife` への読み取り専用試験 `tests::public_github_next_link_smoke` は、製品 Rust の `next_page` を使用した１ページ目から２ページ目の取得と２ページ目の JSON デシリアライズが成功。`cargo test --locked --offline tests::public_github_next_link_smoke -- --ignored --exact`、終了コード0、１件成功。ログ `public-read-01.log`。
- 無効な合成トークンの試験 `tests::public_github_rejects_invalid_synthetic_token` は実 GitHub の HTTP 401 と表示用エラーへの合成トークン非混入を確認。終了コード0、１件成功。ログ `public-invalid-token-01.log`。いずれも実 PAT、アプリ GUI、Issue 書込みは使用していない。
- 製品 `widget/src-tauri/src/main.rs` SHA256 `61595B68317E15FDD8F2BED88B920A468D5516740E3D3124710384709C52FC24`。直前に Rust 通常67件・URL 許可範囲1件が成功、10件は ignored。リリースビルドも成功。実行ファイル SHA256 は上記。詳細は `product-test-result-01.md`、独立確認は `product-review-01.md`。
- PAT はユーザーが後日準備予定で、値は受け取っていない。GitHub CLI 保存済み認証は無効と報告された。公開検証用 Issue の作成・移動は未実施。既存の限定された承諾と未承認の実行方式は `docs/handoff-20261121.md` と `product-decision-01.md` を参照。

## 再開時に必要な作業

1. 同種失敗の回数を今回の処理と過去の累計に分ける。F-078 は２件であり、次回以降も再発時は `docs/failure-log.md` の集計・独立分析規則に従う。標準エラーと終了コードが取得されなかった初回の原因を断定しない。
2. GUI 起動の実行環境・隔離先・WebView2・終了コード101の根拠を、再実行前に既存の証拠から切り分ける。秘密や既存設定を保護し、必要なら事前に出力と終了状態を安全に捕捉する設計を検討する。今回の２つの fixture は保護する。
3. 修正後リリース版の Windows 上の表示、移動・サイズ変更・最前面・外部リンク、PAT 登録・更新・削除と再起動後の読取り、実 GitHub での作成・全列移動、障害時の挙動を Issue #1〜#7 の完了条件に照合する。実書込み前の対象確認と安全な実行方式の承認は未完了。

## 制約と証拠

- リポジトリ `main` の未コミット差分と過去 run の成果物を保護。GUI fixture の削除・ユーザーの資格情報変更・既存 Issue の変更は行っていない。
- 認証情報の準備をユーザーが回答するまで、PAT を必要とする検証は実施できない。認証情報をチャットに求めない。
- 同種２回後の停止を優先し、この引き継ぎと失敗記録の保存・読戻し以外は実施しない。
