2026-11-21。ユーザーは「issueを確認し、アプリを完成させてください。同じ失敗が2度続いた時は引き継ぎの資料を作成して、セッションを中断してください。」と依頼し、前回の中断後「続行してください」と指示した。

## 中断理由

実アプリを使わない `job_list_probe.py` は `synthetic_job_list=failed`、終了コード1で、失敗段階を記録できなかった。次に子を生成せず Job 作成のみを確認する `job_capability_check.py` が `job_capability=failed stage=create`、終了コード1となった。最初の試験も冒頭で Job を作成するが、当時の失敗段階と内部原因の同一性は未確認。同じ Job による起動方式の失敗が続いたものとして安全側に数え、中断した。`docs/failure-log-001.md` に F-081 発生1・2 として記録。

最初の試験は合成の no-op Python 子のみを対象とするが、例外時の終了確認は不十分で、CIM によるコマンドライン照会も利用できず、残存の有無は未確認。対象と無関係なプロセスを終了しない。実アプリ、PAT、Credential Manager、GitHub の書込みは使用していない。

## 再開時
