# Closed Issue の分類判断

Issue #1・#4 の文面は Closed とステータスラベルが矛盾する場合に複数解釈が可能で、元の共有チャット本文は取得できなかった。2026-11-21、ユーザーに「Closed を優先して Done に表示（推奨）」と「ステータスラベルを優先して表示」を提示したところ、「推奨通りにしてください」と回答した。よって Closed はラベルにかかわらず Done とし、Open はステータスラベルを Todo → In Progress → Done の順で優先し、該当なしなら Todo とする。
