複数結果を一括表示し、外側の出力上限を超えたことはレビュー担当の報告に基づく。各結果の実際の長さ、包装による増分、個別の終了コードは未確認であり、どの結果が超過を決定づけたかは断定できない。

`recurring-lessons.md` の F-001 と `AGENTS.md` は、合計出力量と内外の上限を先に見積もり、並列取得と表示を分け、個別に短い必要範囲・終了コードを取得するよう明記する。切り詰められた表示を完全な証拠とせず、安全な再取得が許される場合も既存の完全なログを優先し、書込みや外部操作を表示確認だけのために再実行しない。今回の事例はこれら既存策を適用する場面に該当する。
