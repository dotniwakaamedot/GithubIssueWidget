## 原因の確度と次の切り分け

位置不変の観測だけでは入力方式・座標・押下時間、IPC、OS の移動処理、またはアプリ実装のどこに原因があるか判定できない。診断記録にあるタイミングや座標は仮説である。実際の現行版の手動移動が可能かも、過去の別版の手動結果から断定しない。
