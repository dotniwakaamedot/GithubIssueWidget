# 同種失敗2回による停止

2026-11-21。ユーザーの「一回の処理の間に同じ失敗が２度続いたらそこまでの経過をファイルに保存して中止」に従い、F-066 の2回目を認識した時点で実装と検証を中止した。前回の停止前レビューと今回の再レビューはいずれも、実 GitHub 検証でプロセスツリーの終了を確認できないことを blocking と判定した。元の失敗は `execution-review.md`、再発は `execution-rereview.md` に記録。

Job Object を用いた `job_process.py` と合成試験を追加し、4テストは終了コード0。ただしパイプ EOF はパイプを閉じて生存する子孫の終了を証明せず、Job の全プロセス終了確認と、異常経路・統合試験が不足する。修正版 `run-live.py` は先頭で無条件に終了するため、実 GitHub 書込みは行っていない。製品 UI・Credential Manager と Issue 作成・移動の実環境検証も未完了。

未コミットの既存成果・ログ・fixture を保持する。再開時はユーザーの新しい指示と停止条件に従い、`execution-rereview.md` の指摘、`handoff.md`、Issue #1〜#7 を確認する。Job 内プロセス数または各終了ハンドルを期限付きで確認し、パイプを閉じた子孫と保持する子孫、API 失敗を合成試験で検証した後、対象版を再レビューする。検証用 Issue の作成結果不明時は再 POST せず、マーカーを全ページ照合する。
