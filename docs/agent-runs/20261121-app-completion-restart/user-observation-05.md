# 検証 Issue と移動経路 05

- ユーザーが作成した対象番号は公開 `dotniwakaamedot/GithubIssueWidget` の Issue #11 と親 `/root` から通知された。GitHub 側の独立読戻しは未実施。
- 全6方向を含み最後に Done とする `To Do → In Progress → Done → To Do → Done → In Progress → To Do → Done` を本人に依頼。非 status ラベル保持と最終 closed も確認依頼中。操作途中でエラーなら停止し、現在の実状態を照合してから再開する。
- 報告待ちであり、全方向の成功・ラベル保持・クローズを完了扱いにしない。対象以外の Issue は操作しない。
