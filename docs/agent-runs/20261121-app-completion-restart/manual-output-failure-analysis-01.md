## 原因と対策

長行の省略は指定した `max-columns`／preview によるもので、元行全体が表示されないことは確認済み。2件のツール上限切り詰めは、記録された出力量が設定上限を超えたことが確認される。いずれも行長・合計量・エラーと包装を含む出力量見積り不足が合理的な原因候補だが、各担当の内部判断過程は断定できない。引数誤りは定義確認前の推測と報告されている。

`docs/instructions/work.md` は取得前に対象・件数・行長と内外の上限を見積もり、長行は行番号・長さを先に調べ、必要な文脈を分割することを要求する。対象が分かる小範囲だけを表示し、長行では preview を完全な原文の証拠とせず、必要な部分を文字単位で分割して各部分・終了状態を確認する。大きい安全な出力は最初から適切なログに保存して範囲を分け、秘密や外部書込みが絡む操作は表示回復だけのために再実行しない。ツール呼出しは定義を先に確認し、エラーは秘密を出さず種別・状態だけを取得する。これらは既存指示の適用であり、新たな方法の再発防止効果は未検証。
