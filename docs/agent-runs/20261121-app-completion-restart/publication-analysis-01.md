## 再発防止と検証

1. 所有者が同一ディレクトリの未使用 .tmp を排他作成し、完成内容を書き込んで閉じる。
2. UTF-8 を厳格に復号し、代表日本語・パス・全内容の一致を読み戻す。内容や機密を不要に出力しない。
