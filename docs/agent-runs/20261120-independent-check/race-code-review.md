## 旧版の blocking 指摘

- 子テストの `assert_eq!(token, "synthetic-old")` は不一致時に読取値を panic 出力へ含める。子テストは単独指定でも起動でき、環境変数や一時領域の内容が意図と異なれば、既存資格情報の値が stderr に出る可能性がある。実漏出は観測していない。詳細は `questions/race-code-security-01.md`。
- 親は固定文言の `assert!` に変更したと報告したが、旧依頼と SHA が異なるため、新版の実体・子の fixture 受入れ条件・残る露出経路を新版レビューで独立確認する。
