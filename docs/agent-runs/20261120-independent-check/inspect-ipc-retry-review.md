# 再検証後の合成資格情報照会：静的レビュー

## 判定

**対象ハッシュに限定して静的レビューを承認。** 実行結果や資格情報の存在・不存在を証明するものではない。

- 対象スクリプト SHA256: `3D083D0A0BE0EF82D058DC5EF79B79FF7F916BA6B8C823A21B406BFB5EA4F48B`。
- 対象ログ SHA256: `CE3D2D242F7FD2410A9992863793B898F19A44C547ADC7D5BA30A204343E88D3`。
- 比較元の既承認スクリプト SHA256: `645D3C30EDE6AB838BD246DD717BB38BF37BB2E67435A283AB0A66F5663A40E0`。

## 確認結果

- 比較元と対象は37行で、差分はログのファイル名と検証するログ SHA256 の2行のみ。対象スクリプトのハッシュとログ実体のハッシュは依頼値に一致し、ハッシュ照合後、同じバイト列から対象を抽出する処理も維持されている。
- 行全体に一致するマーカーを1件だけ許可する。対象ログの読み取り専用文字列検査では1件と確認した。サービス名、ID、値は出力していない。
- `CredReadW` に渡すターゲットは Windows `keyring` の `username.service` 規則に沿い、Generic 種別1、flags 0 を使用する。値を表示せず、成功時は `CredFree` する。`CredWrite` / `CredDelete` は呼ばず、結果の出力は存在・そのセッション内で不在・不明の分類のみ。

## 制約

- `CredReadW` は資格情報のデータを呼出しプロセスのメモリに渡し得る。値を参照・出力しないことと、メモリが完全に消去されることは別であり、後者は未確認。
- 不在は実行ユーザー・ログオンセッション内の照会結果であって、失敗した元の試験と同じ資格情報領域かは別途確認が必要。他のセッションを含む不存在は証明しない。
- 実行前には親担当がスクリプトの対象ハッシュと実行環境を再確認する。ログはスクリプトが読み取ったバイト列のハッシュを照合する。

## 実施範囲

ファイル存在・SHA256・静的差分・識別子を表示しないマーカー件数を確認した。対象スクリプトの実行、資格情報の照会・変更・削除、GUI 操作、秘密・値・ID の出力は行っていない。
