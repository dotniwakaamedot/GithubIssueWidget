# 出力対策の独立レビュー依頼

ユーザー原文: 「この対策をレビューしてより作業を止めないアイデアを提案してください」

対象は `AGENTS.md` の作業の基本方針に追加された出力取得・ログ・切り詰め後の3項目と、`docs/recurring-lessons.md` の F-001。既存のユーザー指定「停止条件は累計ではなく、一度の指示と処理の間の回数」と、失敗時の独立分析・記録を尊重し、安全性と進行を両立する提案を優先する。曖昧な条件、不必要な同期停止・ログ記録・事前確認、出力予算や安全上の欠落を具体例・優先度付きで指摘し、対象版のハッシュと共に `output-rule-review-result.md` に記録する。読み取りのみ、プロジェクトファイルの編集・実行・外部通信は禁止。内容を要約して直接通知せず、結果ファイルの絶対パスのみ通知する。
