# 子プロセス終了待機の期限について

- 対象 `widget/src-tauri/src/main.rs` SHA256 `54A32EE8E7E9434A4135CE94885C7B65EB9FFFAF24734E538F2E990D64165719`。
- 事実: 子の 40 秒期限超過時、`child.kill()` が成功すると直後に `child.wait()` を呼ぶ。`wait()` 自体には期限が設定されていない。
- 影響: 強制終了要求後も OS がプロセス終了を直ちに確定できない場合、テストが意図した期限を超えて待機する可能性がある。実際の停止やハングは未観測。終了を確認できない間に資格情報を削除しない現在の方針は維持する必要がある。
- 推奨: `kill` 後も期限付き `try_wait` などで終了を観測し、期限内に確認できなければ子と fixture・合成 ID の状態を不明として保持・報告する。OS のプロセス終了要求が即完了することを前提にしない。
- テスト実行、プロセス操作、GUI、資格情報・外部サービスへのアクセス、製品ファイル変更は行っていない。
