# 出力切り詰めの独立分析（追加情報）

- 確認された事実: 担当の追加報告によると、`AGENTS.md` と `docs/recurring-lessons.md` の各冒頭46行を一括表示した結果は2596 tokens で、外側の出力上限2500 tokensを超えて切り詰められた。
- 原因: 複数の資料をまとめた出力量が外側の上限を超えたことが、報告された数値から確認できる。各ファイルの寄与、欠落した箇所および内容は未確認。行数の指定だけではトークン数を保証できない。
- 同種性: 既存 F-001 と、出力量が取得上限を超え出力の一部を確認できない現象、および事前の範囲限定・分割という予防策を共有する。個々の事象は二重計上せず、再表示や追加情報を新たな発生と数えない。
- 予防策: ファイルごと・必要な節ごとに取得し、長い行も考慮して各取得の出力量に余裕を設ける。長文はファイル保存や分割を用い、内側と外側の上限の両方を確認する。
- 実施範囲: 追加依頼の読取りと本結果の新規作成のみ。追加ファイルの読取り、元操作の再現、外部通信は行っていない。
