## P01: パッチをファイル・箇所単位で直前照合する

- 優先度: 高。根拠は上記発生7〜9。次担当: 変更担当・進行管理。
- `AGENTS.md` の追記案: 「既存ファイルへのパッチは、対象ごとに適用直前の実ファイルを読み、各アンカーの文字列・出現順・一意性を確認する。ハッシュも転記せず現在の値を照合し、複数ファイルや離れた箇所は可能な範囲で別操作にする。拒否時・並行編集後は現行版を再確認し、ユーザーの停止条件に達した後の経過保存でも確認を省かない。」
- 期待効果: 誤った見出し、値、文脈の順序が理由の拒否を低減。費用: 確認・操作回数が増える。リスク: 照合と変更の間の並行編集は防げず、単一ファイル内の複数箇所を必ず別操作にできるとは限らない。
- 効果確認: 次の変更と停止時の記録で各対象・アンカーの確認、適用結果と失敗回数を記録する。１回の成功だけで再発防止を断定しない。

Skill 提案なし。既存ルールの具体化であり、新しい Skill が必要という根拠は未確認。P01 の採否・反映、登録先権限と重複の確認は管理者が判断する。
