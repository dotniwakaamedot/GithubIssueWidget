# F-001・F-075 の独立分析依頼

ユーザー原文: 「同じ失敗を繰り返したら、複数エージェントで検討を行い、対策をルールに追記してください。」また、一回の処理で同じ失敗が２度続いた場合は経過を保存し中断する。

`stop-03.md`、`docs/failure-log-001.md` の F-001 発生42・F-075・F-064、関連する `docs/recurring-lessons.md`、`AGENTS.md` を確認する。F-001 の切り詰め、F-075 の取得失敗・配列の誤集計について、既存 ID との関係、事実・不明な原因、具体的なルール追記案を独立分析する。元の処理を再実行せず、各出力は１文書の短い範囲に限定し、失敗が２回続けば中断する。担当ごとに `restart-failure-review-a.md` または `restart-failure-review-b.md` に結果を記録し、パスを通知する。他者の変更・中断時の一時ファイルを保護し、製品や他担当ファイルを編集しない。改善・Skill 提案の有無を明記する。
