# 繰り返した失敗の複数担当による検討

ユーザー原文: 「同じ失敗を繰り返したら、複数エージェントで検討を行い、対策をルールに追記してください。」先行原文: 「Issue を確認しアプリを完成させてください。一回の処理の間に同じ失敗が２度続いたらそこまでの経過を引き継ぎ用ファイルに保存して、中断してください。」

F-001 の発生40・41 および F-073 の二度の合成試験失敗について、`docs/failure-log-001.md`、`docs/recurring-lessons.md`、`../20261121-resume-control/stop-03.md`、既存の `f001-review.md` と `f001-review-02.md` を参照し、担当者それぞれ独立して事実、原因の確度、具体的で実施可能な再発防止策、既存ルールへの追記案、未確認事項を分析する。処理を再実行しない。結果は担当ごとに `repeated-failure-review-a.md` または `repeated-failure-review-b.md` に保存し、パスを通知する。製品・他担当のファイルを変更しない。ユーザー指定の停止条件を優先する。

追加: `state-review-02.md` の F-016 についても同様に検討する。Issue 番号をタイトル検索語として使った検索は空となり、番号での直接取得で確認できた。元検索は再実行しない。
