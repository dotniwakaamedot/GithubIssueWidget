# F-001 独立分析

- 対象: `f001-review-request.md` に記載された 2026-11-21 の親の出力切り詰め。参照: `AGENTS.md` の作業の基本方針、`docs/agent-workflow.md`、`docs/recurring-lessons.md` の F-001、`docs/failure-log-001.md` の F-001。
- 確認された事実: 依頼書と会話上のツール結果では、複数の資料の出力に GitHub ツールの説明全文を加えて一括表示した結果、全体の出力が切り詰められた。欠落部分は確認できない。ツールの説明の件数や各結果の厳密な出力量は分析していない。元操作は再実行していない。
- 原因の評価: 複数結果と説明全文の合算量を表示前に十分限定しなかったことが直接観察できる。実際に上限を適用した層や、各結果の正確な寄与は未確認。F-001 の既存例 37・38 と同様、合算出力の管理が対象である。
- 対策: 既存の `AGENTS.md` と F-001 の教訓は、個々の必要範囲、複数結果の合計と内外上限を考慮し、個別表示することを明記しており今回にも適用できる。GitHub ツールの探索では説明全文を列挙せず、先に名前だけを限定して、必要なツールの定義のみ表示する。並列取得する場合も結果の表示は分ける。欠落部分は未確認として扱い、再取得が必要で許可される場合のみ安全な範囲に分ける。
- 停止条件: 今回の同種失敗は依頼時点で１回。累計と当該処理内の回数を区別し、同種の失敗が続けて２回になった場合はユーザーの指示を優先する。
- 新規改善案・Skill 提案: なし。上記の方法は既存ルールの具体的適用であり、追加の制度・ツールを提案するものではない。既存ルールだけで再発が防止されたことは未検証であり、以後の出力を確認する必要がある。提案なしのため Issue 本文案は作成しない。
