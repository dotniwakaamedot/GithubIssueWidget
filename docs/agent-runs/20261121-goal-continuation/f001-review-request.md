# F-001 独立分析依頼

ユーザー原文: 「Issue を確認しアプリを完成させてください。一回の処理の間に同じ失敗が２度続いたらそこまでの経過を引き継ぎ用ファイルに保存して、中断してください。」

2026-11-21 の今回の処理で、親が引き継ぎ・教訓・Issue 手順の出力に加え、GitHub ツールの説明全文を一括表示したところ、全体が切り詰められた。欠落部分は未確認であり、同じ処理中の F-001 は現時点で１回。既存の `docs/recurring-lessons.md` と `docs/failure-log-001.md` の F-001 を参照し、原因の確度、既存予防策の妥当性、追加対策を独立して分析する。外部書込みや元操作の再実行はしない。結果をこのディレクトリの `f001-review.md` に記録し親に通知する。製品コードや他者の変更は編集しない。
