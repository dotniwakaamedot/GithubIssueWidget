1. 発生7は存在しない見出しをアンカーに指定したため拒否されたと記録されている。現行の先頭見出しは `# Failure log 001`。発生8は二つの対象ファイルにわたるパッチで、一方の文脈に誤った SHA を指定し拒否された。発生9は停止後の失敗記録追記で実ファイルと逆の文脈順序を指定し拒否された。各パッチは適用されなかったと停止記録と失敗記録にある。

## `AGENTS.md` への具体的追記案

> 既存ファイルへのパッチは、対象パスの存在と現在の対象箇所を適用直前に読み、文脈文字列・ハッシュ・出現回数・複数箇所の順序を各ファイルごとに照合する。記憶や別ファイルの値をアンカーに使わない。独立したファイル変更は可能な範囲で別パッチに分け、各パッチの結果と対象を読み戻す。同一パスの変更は一つの更新操作にまとめる。対象が一致しない場合は原因を調べ、適用指示とユーザーの停止条件が許すまで再試行しない。

見出しや SHA を外形だけで決めず、適用直前に各ファイルから取得した値を照合することで発生7・8を、実際の順序の確認で発生9を対象とする。連携中の他担当が直後に書き換える可能性は残るため、照合は排他や成功を保証しない。失敗記録の経過保存にも同様に適用するが、再試行可否は停止指示が優先される。追加後の読戻しと次回利用時の効果確認が必要。
