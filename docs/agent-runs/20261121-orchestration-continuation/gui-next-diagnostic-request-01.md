# GUI 観測不能の次の原因診断

担当は親が指定する。`gui-release-observation-result-01.md` と `gui-window-identification-01.md` を照合し、対象 EXE の直接生存・HWND 非列挙・強制終了を、実際の画面非表示・以前の101・原因確定と区別する。旧の不明プロセスと未追跡子孫は推測終了しない。

通常の対話デスクトップで本人が識別できる画面を得る利用可能な手段と、今回の実測で欠けた session/desktop・WebView2 初期化・窓の識別・エラーについて、**新たな情報を得る**具体的な診断方法を検討する。既存の承認済み操作・CUA の利用範囲とデータ保護を守り、同じ DEVNULL 起動をそのまま繰り返さない。出力に秘密を含む可能性がある場合は固定分類・限定収集や保護された出力を用い、保持・読戻しと終了確認を具体化する。候補が利用不能なら未確認とし、無関係な静的・合成作業は継続する。

新たなプロセス・GUI 起動や権限変更を行わない読取り調査とし、実際に根拠となる文書・バージョン・利用可能性、実行条件、期待する観測、失敗時の安全な停止と残余リスクを固有結果に記録する。個別の実行には対象・方式・所有を固定し別担当が確認する。不要な計画や既合格試験の反復はしない。
