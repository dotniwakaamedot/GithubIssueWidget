1. 既存の旧 worktree と branch を変更・削除せず、隔離版・試験結果を SHA 固定のまま保存。上記の実質的な重なりと変化を別担当にレビューしてもらい、旧版から要取り込み差分が残る場合は明示する。

## 確認方法と制約
