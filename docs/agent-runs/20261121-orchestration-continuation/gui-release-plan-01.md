## 直接起動と観測

独立レビュー後、実行者が一度だけ**固定した EXE のフルパスを直接**、専用環境と作業場所で起動する。入力・環境からトークンを除き、標準出力・標準エラーは秘密の漏出を避けるため OS の null 宛に捨てる案。これは出力による原因診断を提供しない。引数は渡さず、自動操作や設定保存・送信はしない。

実行ツールが直接プロセスの生存を継続追跡できるハンドルを保持する方式を固定し、PID・開始時刻・実体パスと EXE SHA を記録する。候補は Python `subprocess.Popen` を直接親とし、`stdout/stderr=DEVNULL`、`stdin=DEVNULL`、固定環境と `cwd` を指定して、所有ハンドルから `poll()`/`wait()` と戻り値を取得する方法。スクリプトはプロセス生成前にレビューし、生成直後の例外・監督者停止時の不明、期限と後続禁止を扱う。PID 一致だけで他ウィンドウを操作しない。`exec_command` の session ID は親スクリプトの状態の証拠であり、WebView2 を含む子孫の存在・消失を保証しない。

初期表示の観測は保持した直接プロセスと一致する HWND / PID を確認したウィンドウに限定し、Computer Use の該当 skill・ガイダンスと現在のツール指示に従う。対象が識別できなければ他の同名アプリやウィンドウを操作しない。確認事項は空設定画面が表示されるか、文字の判読、エラー表示の有無、直接プロセス生存。ウィンドウの見た目の成功と終了コードを別々に記録する。画面は取得前に機密表示がないことを検討し、保存するなら許可された最小範囲とする。

観測後に同じ確認済み HWND の通常の閉じる操作を行い、直接プロセスが期限内に終了することと終了コードを保持ハンドルから確認する。例として表示待ち30秒・終了待ち15秒を候補にし、実行計画で固定する。期限超過は異常または未確認として停止し、直接プロセス・捕捉した識別子・専用領域を保全、別担当が調査する。識別不能なプロセス、旧合成子や WebView2 共用プロセスを検索名だけで停止しない。直接プロセスが終了しても未追跡子孫の終了・旧プロセスとの非干渉は証明しない。

対象が表示されず終了101なら失敗として正確なコード・観測・時刻を記録し、同じ診断情報しか得られない起動を繰り返さず、F-078 の原因・安全な診断方式を別担当に調査させる。未終了・観測不能・出力欠落を成功扱いせず、独立分析の後に次の方式を決める。コード101や `WebView2` に関連する過去の文字列だけでは原因は特定できない。
