## 結果と静的な発見

隔離コピーに、初回 GET の後に他者が対象以外のステータスを追加、対象ステータスを削除、state を変更した場合の最終値を返す3ケースを追加した。既存 `final_status_conflict_is_not_reported_as_success` は余分なステータスを検出するが、書込み済みの可能性について通知することや対象ラベルの消失・state 不一致を個別に検証していない。今回の応答列は順序固定の合成であり、真の並行操作や実 GitHub の挙動の再現ではない。

各新規テストは POST・DELETE・PATCH・最後の GET が行われたこと、最終結果が成功でないこと、先行書込みの一部反映があり得る旨をエラーで通知することを独立期待値として検査する。試験案では日本語の `一部` を通知の具体的な判定語としているため、文言の同義表現を許容するかを独立レビューで確認する。

**静的観察:** 現行 `move_in_repo` の最終不一致時のメッセージは「更新後の状態またはラベルが一致しません。最新状態を確認してください。」で、先行する書込みの一部反映の可能性を明示していない。最終不一致をエラーにする挙動は確認できるが、計画が求める部分反映通知との不一致がある。ここからテストが失敗すると推測されるが、実行していないため実測した失敗とはしない。製品を勝手に変更せず管理に判断を依頼する。
