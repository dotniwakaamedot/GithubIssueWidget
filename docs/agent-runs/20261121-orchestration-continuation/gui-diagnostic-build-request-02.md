# 診断版ビルド担当と既存環境の保護

`gui-build-handoff-01.md` は旧 release ビルド完了と書込み停止を確認する一方、専用領域 ACL により別担当からアクセス拒否になり得ると記録。不要な依存の大量コピーや権限変更を避けるため、既存領域の所有者 `/root/gui_failure_investigation` を診断ビルド担当とする案を親に提案する。前版 `gui-diagnostic-build-request-01.md` の作業範囲・固定診断版・別担当レビュー・実行条件を継承する。

旧 build の EXE とログ・status・manifest を上書きせず、出典と置換前の入力の SHA と保存先を固定。現行製品への書込みは禁止。診断版の固定ソース2ファイルを配置して専用 target を再利用する場合は、前版 EXE/ログを保護した上で新しいログ・status・生成 EXE 保存先を使用し、現行入力との対応を再確認する。旧 target の個々の生成物が更新され得ることと未追跡子孫の不明を記録する。別担当による固定版確認と親の開始通知前には実行しない。
