# dubious ownership の追加事実の確定依頼

- 担当 `/root/issue_survey`。親から旧 worktree 所有者と sandbox 実行者の相違に関する追加一次事実の報告を受けた。確定済み `dubious-ownership-investigation-01.md` を上書きせず、別ファイル `dubious-ownership-addendum-01.md` に記録する。
- 安全に開示可能な範囲で取得方法・対象・時点・終了結果、比較による確認事実と直接確認できていない Git 内部の判断・原因を区別し、個人名・SID・不要なパスや資格情報を記録しない。既存結論に対する影響と未確認を示し、結果の SHA を確認してパスを通知する。
- 読取りで取得済みの事実を記録し、所有権・Git 設定・既存ログを変更しない。確定版は後に記録担当が隔離案に反映する。
