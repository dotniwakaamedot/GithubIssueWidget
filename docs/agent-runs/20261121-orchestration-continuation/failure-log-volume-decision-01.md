# 失敗記録の隔離分冊・索引の所有範囲

`/root/process_safety` は既存 `failure-isolated-01/` に限り、`docs/failure-log.md` の現行版を確認・独立複写した `failure-log.md` と、新規で存在しない `failure-log-002.md`、既存の隔離 `recurring-lessons.md` を所有してよい。既存の `failure-log-001.md` は上限直前のため、102,400 bytes を超える追記をせず、`docs/failure-log.md` の分冊・索引手順と各発生の重複照合に従う。基準本体・他担当・既存分冊を保護し、既存ファイルに予期しない差異があれば中止する。
