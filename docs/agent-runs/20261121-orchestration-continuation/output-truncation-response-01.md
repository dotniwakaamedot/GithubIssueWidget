# 認証監査中の出力切り詰めへの対応

- 親は `/root/project_survey` の認証監査中 `rg` 出力切り詰め1件を報告。実際の対象・検索条件・終了結果・再取得範囲・情報の安全性を当事者の確定結果に記載し、欠落を不存在の証拠にしない。元出力を復元済みと扱わない。
- 先行の別担当分析 `output-failure-independent-01.md` と `output-failure-second-agent-01.md`、既存 F-001 の教訓に基づき、対象ファイルと条件を絞り、出力前に件数・最大行長と内側/外側の上限・包装分を見積もり、必要な区間だけ分ける。秘密を含み得る結果を未保護ログへ表示しない。
- `/root/process_safety` は当事者の結果と既存記録を重複照合し、1件の隔離追補と再発防止効果未確認を記録する。今回以外の同種件数を混同しない。ユーザーの2回条件を満たす場合は当事者以外に調査を依頼する。確定済みの記録や共有本体を勝手に上書きしない。
