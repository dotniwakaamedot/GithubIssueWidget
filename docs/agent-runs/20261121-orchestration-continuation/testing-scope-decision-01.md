# 試験とレビューの範囲

ユーザーは過剰なテストの繰返しを懸念している。実際の試験再実行と、準備・静的レビューを区別する。**同一版で合格済みの試験は、新たな変更・失敗・未解決の懸念などの理由がなければ再実行しない。** 同期修正の Vitest 39件、同一入力の型検査と Vite build は既存の成功証拠とその独立レビューを利用する。

必要な未実施要件や新たな変更に直接対応する最小限のテストを選ぶ。計画・レビューの新規作成は適用指示を満たす範囲で実行に必要なものに絞り、同じ内容の資料や分析を重ねない。失敗・未確認は従来どおり区別し、同じ失敗2回の別担当調査指示と秘密・既存作業の保護は維持する。ユーザーが別途求めた検証の客観レビューは進行する。
