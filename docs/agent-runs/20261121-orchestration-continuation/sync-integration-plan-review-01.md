| 項目 | 根拠・判定 |

| 変更の保護 | main.rs・旧 worktree・未追跡・他ファイルを保持し、作業前後の SHA、1担当、差異時中断と独立レビューを要求。SHA は競合検知に有用だが旧担当の終了や別セッションの書込み停止を証明しない。 |

| 完了と検証 | 最終差分、対象版、独立レビュー、実行可能な型・試験と未実施を記録。実 GUI、API、子孫・PR と他 Issue は別途必要。 |

## 確認方法

`D:/Projects/GithubIssueWidget` で計画・依頼・`docs/instructions/delegation.md`・旧所有権と PR 履歴・限定試験レビューを読取り照合し、`Get-FileHash -Algorithm SHA256` は開始・終了とも一致、終了0。旧担当・PR の最新外部状態は再調査していない。テスト、製品変更、GUI、外部書込みは行っていない。対象版変更後は新版を独立レビューする。
