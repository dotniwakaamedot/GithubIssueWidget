# 残りの中間質問の個別整理

`/root/cleanup_execution` は `cleanup-execution-interruption-01.md` のとおり、先頭1件の削除・不存在確認後に参照走査で失敗し停止した。原因は推測であり同じ走査を再実行しない。最初の削除結果と `.tmp` を保持する。

残りの16件は `cleanup-execution-request-01.md` と `cleanup-list-answer-01.md` に固定された対象に限る。**run 全域の検索・再帰列挙はしない。** `/root/cleanup_survey` が既に内容・後続解決を確認した事実と、各対象・既知の対応する後続ファイルを個別に読み、前回と異なる単純な方法で削除前の所有・使用・通常ファイル・絶対パスを確認する。対象以外の参照を網羅できない場合は参照切れが残り得ると結果に明記し、不明・使用中・範囲外は保留する。削除は承認された17個のうち未削除の個別ファイルだけ、`Remove-Item -LiteralPath` で実施し、1件ずつ読戻す。最初の1件を再削除しない。

対象外の全ファイル・ディレクトリ、製品・実行ファイル・Git・外部状態は保護。新たな同種失敗が再発したら直ちに停止し別担当に調査を依頼する。初回の2種類の失敗と今回の実際の削除・保留・失敗、後続根拠・参照切れの限界を `cleanup-execution-result-01.md` に確定し通知する。
