- 目的: 現 checkout に統合した2ファイルと同内容の固定入力で TypeScript 型検査・Vite 製品ビルドを行い、先行の39件モック試験を補完する。実 Windows UI・実 GitHub・Credential Manager・スリープ確認ではない。
- 現版 `widget/src/main.tsx` SHA256 `6FCF2A34145450C5029B7FF80DDB3EC1DA5E27173AAB84E57F16D6D54C0E6A3E`、`widget/src/main.test.tsx` `66E118A5A7062854C23BE405D2E9578C974FA283BEA332F2A7C51DCA1BFFD13C`、隔離 fixture の同一 SHA を開始前後に確認。差異や他担当の編集があれば実行せず再評価する。前回固定 manifest・専用領域・既知の生成物の現在状態も照合し、未知の変更を保護する。
- 先行の承認済み方式 `sync-practical-test-plan-01.md` と同じ独立 fixture・Node・依存、秘密を渡さない環境と専用ログを利用する。先行試験が正常に直接終了し、依存・入力のハッシュは直後照合で一致したが、未追跡子孫の終了や依存全体の通信・OS 資格情報へのアクセス不存在は証明されていない。旧 GUI 合成子とは目的・対象が異なるが同じ OS とアカウントの共有リスクは記録する。
- Vite build には `widget/index.html` が必要。実行者が実在と SHA・内容を事前確認し、既存 fixture に同名ファイルがなければ通常の独立ファイルとして複写し、複写前後・実行後の出典とコピーを照合する。`dist`・ログ・cache 等の生成物は fixture 内の専用位置に限定し、元の製品・依存・旧 fixture・Git を変更しない。既存の未知のファイルを上書きしない。
- 作業ディレクトリは fixture `project`。固定の Node 実体で `node_modules/typescript/bin/tsc --noEmit` を実行後、成功した場合に `node_modules/vite/bin/vite.js build` を実行する。それぞれ stdout/stderr を個別の新規専用ログへ分離し、各直接プロセスの終了コードを直ちに捕捉、出力の欠落と終了を区別する。ツールがセッション ID を返した場合は同じ ID を待ち、時間切れを終了とみなさず、未知・旧プロセスを推測して停止しない。
- 実行前にコマンドの対象実体とバージョン、専用環境、出力先・空き容量、前回生成された `localappdata/vitest/.vitest-secret-token` を内容を読まず保護し、通常の Node/Vite が意図する範囲以外を触らない設計を確認する。予期せぬ入力・権限・不明な状態では開始しない。結果・生成物を消去しない。
- テスト版と製品版の一致、各終了コード、生成物の成否・ログの完全性と子孫の未確認、失敗・残余リスクを別々に記録。作者以外が固定版と証拠を確認する。同じ失敗2回時は別担当に調査・解決を依頼する。実行結果が全 Issue の完了承認に代わることはない。
