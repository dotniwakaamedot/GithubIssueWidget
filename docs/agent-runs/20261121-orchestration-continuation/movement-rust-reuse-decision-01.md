# Rust 試験環境の再利用方針

親の指示に従い、13,546ファイルの不要な重複コピーを避ける。`pagination-test-execution-01/` は現在 `/root/issue_survey` が使用中のため、同時には触らない。直接プロセスの終了・ログと入力/target の状態・旧担当の書込み停止を確定結果で確認し、既存結果・ログと追加試験の証拠を上書きしない条件で、`/root/existing_work_review` に環境の限定的な所有を移管する。

移管後、現行 main・レビュー済み movement の SHA、Cargo.lock・専用 CARGO_HOME/target とローカル環境を照合し、必要な movement のみ明示的に差し替える。pagination の入力とログは元版・ハッシュを保持し、対象と履歴を混同しない。追加3件に限って実行し、結果・終了・入力版・未確認を分ける。未終了、所有・内容不明、差し替えが他成果を損なう場合は再利用せず、別の安全な方法を判断する。既に成功した他のテストを無理由に再実行しない。
